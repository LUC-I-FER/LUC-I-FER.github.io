Smart Watch

The Smart Watch is a compact wearable device built around the ESP32, designed to deliver real-time timekeeping, wireless data access, and a smooth user interface. It features a vibrant GC9A01 circular TFT display and synchronizes date and time using NTP servers (pool.ntp.org) to ensure highly accurate clock performance.

The system leverages FreeRTOS concepts for task-based scheduling, enabling parallel execution of display updates, time synchronization, Wi-Fi handling, and SD card operations. This ensures consistent responsiveness, minimal latency, and efficient resource utilization.

Equipped with an SD card module and a built-in HTTP server, the smartwatch doubles as a wireless file storage system, allowing users to upload, download, and manage files directly through a web browser. With its modular architecture, real-time capabilities, and clean design, the project demonstrates a robust and fully functional DIY smartwatch platform.

Key Features

  • Real-Time Timekeeping: Automatic date and time synchronization using NTP servers (pool.ntp.org) for high accuracy.
  • GC9A01 Round Display: Vibrant 1.28” circular TFT display for watch faces, system status, and UI elements.
  • FreeRTOS-Based Multitasking: Dedicated tasks for display rendering, NTP synchronization, Wi-Fi handling, and SD card operations ensure smooth and responsive performance.
  • Onboard HTTP File Server: Built-in Wi-Fi web server allowing users to upload, download, and manage files wirelessly through any browser.
  • SD Card Storage System: Acts as a portable personal storage device with support for file reads, writes, and directory management.
  • Modular Firmware Design: Clean task separation with message queues, semaphores, and shared resources for stability and efficient real-time performance.

Technology Stack

ESP32 FreeRTOS C / C++ Platform IO Framework GC9A01 Round TFT Display SD Card Module HTTP Web Server Wi-Fi Communication NTP Time Sync SPI Interface RTC (Software / NTP) Li-Po Battery Buck Converter
